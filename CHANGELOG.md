# Changelog

## 1.2.0

- Собственное оформление: тема VOT, логотип, заголовок настроек «YouTube VOT».
- README, CHANGELOG и манифест Homebrew Channel в корне репозитория принадлежат проекту.

## 1.1.0

- ID приложения — `youtube.leanback.v4`: кнопка YouTube на пульте, трансляция с телефона
  и голосовой поиск открывают YouTube VOT.
- Оригинальная иконка YouTube.
- Версия приложения смещена на +100, чтобы LG Content Store не заменял его официальным YouTube.

## 1.0.0

- Новая основа с отдельной сборкой для webOS 3–6.
- Закадровый перевод VOT, панель на красной кнопке.
- На webOS 5 и старше YouTube запускается в облегчённом режиме.
- Обновления по воздуху через Homebrew Channel.
